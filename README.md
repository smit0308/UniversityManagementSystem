# 🎓 University Management System

## 🚀 Overview
The **University Management System** is a robust web application designed to efficiently manage student, faculty, and academic records. Built with **Python, Flask, and MongoDB**, this system provides secure authentication and **role-based access control** for students, faculty, and administrators.

---

## 🛠 Tech Stack
- 🐍 **Python** (Flask) - Backend Framework
- 🍃 **MongoDB** - Database for storing user and academic records
- 🎨 **HTML, CSS, JavaScript** - Frontend Technologies
- 🔄 **Jinja2** - Templating Engine

---

## ✨ Features
✅ Secure **Login & Authentication** 🔐  
✅ **Role-Based Access Control** (Admins, Faculty, Students) 👩‍🏫👨‍🎓  
✅ **Student Record Management** 📋  
✅ **Faculty Information Handling** 📚  
✅ **Academic Results Processing** 🏆  
✅ **Dynamic Data Retrieval from CSV & Database** 📂  
✅ **User-Friendly Interface** 🖥️

## 🛠 Installation & Setup
### 📌 Prerequisites
Ensure you have **Python 3+** and **MongoDB** installed on your system.

### 🔽 Clone the Repository
```bash
git clone https://github.com/smit0308/UniversityManagementSystem.git
cd UniversityManagementSystem
```

### 📦 Create & Activate Virtual Environment
```bash
python -m venv venv
# Activate virtual environment:
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate
```

### 📥 Install Dependencies
```bash
pip install -r requirements.txt
```

### 🚀 Run the Application
```bash
python app.py
```

The application will be available at **http://127.0.0.1:5000/** 🌐
